Overview

What is Elementor MCP Server?

Elementor MCP Server is a lightweight Model Context Protocol server designed specifically for WordPress Elementor. It facilitates CRUD operations on Elementor page data, streamlining content management and AI-driven development workflows.

  • Full CRUD on Elementor page data via natural language or API calls
  • Plug-and-play integration with Claude Desktop via Smithery
  • Uses WordPress Application Passwords — no custom plugins needed
  • Cross-platform: MacOS, Linux, and Windows
  • Open source under the MIT License

Explore the repository and start integrating Elementor MCP Server today. For advanced project management, check out the companion Elementor Project Workflow.

Available MCP Tools

create_page
Creates a new WordPress page with Elementor data. Returns the new page ID.
get_page
Retrieves a page by ID including the _elementor_data meta field.
update_page
Updates title, status, content, or Elementor data on an existing page.
delete_page
Deletes a page by ID with optional force/bypass trash flag.
download_page_to_file
Downloads a page and saves it locally — optionally Elementor data only.
update_page_from_file
Updates a page using Elementor data read from a local file.
get_page_id_by_slug
Retrieves a page ID by its URL slug — useful for dynamic lookups.
Installation

Get Up and Running in Minutes

Install Elementor MCP Server via Smithery CLI for one-command setup, or configure it manually using the mcp.json file with your WordPress credentials.

Method 1 — Automatic install via Smithery Recommended

Run a single command to install and configure Elementor MCP Server directly into Claude Desktop.

bash 
npx -y @smithery/cli install @aguaitech/Elementor-MCP --client claude

Method 2 — Manual configuration via mcp.json

Add the following block to your mcp.json file. See the platform-specific commands below.

json — mcp.json 
{
  "mcpServers": {
    "Elementor MCP": {
      "command": "npx",
      "args": ["-y", "elementor-mcp"],
      "env": {
        "WP_URL": "https://url.of.target.website",
        "WP_APP_USER": "wordpress_username",
        "WP_APP_PASSWORD": "Appl icat ion_ Pass word"
      }
    }
  }
}
json — mcp.json (Windows) 
{
  "mcpServers": {
    "Elementor MCP": {
      "command": "cmd",
      "args": ["/c", "npx", "-y", "elementor-mcp"],
      "env": {
        "WP_URL": "https://url.of.target.website",
        "WP_APP_USER": "wordpress_username",
        "WP_APP_PASSWORD": "Appl icat ion_ Pass word"
      }
    }
  }
}
Variable Description Required
WP_URL The full URL of your WordPress website (e.g. https://example.com) Yes
WP_APP_USER Your WordPress login username (not the application name) Yes
WP_APP_PASSWORD WordPress Application Password — spaces must be kept as-is. Generate one in Dashboard → Users → Application Passwords. Yes
Supported Platforms

Works Wherever You Work

Elementor MCP Server supports MacOS, Linux, and Windows with platform-specific commands and environment configurations for each.

macOS

macOS

Use npx directly in the command field. Standard MCP server launch for Claude Desktop on Mac.

"command": "npx", "args": ["-y", "elementor-mcp"]
View Config
Linux

Linux

Same npx command as macOS. Ensure Node.js is installed and accessible in your PATH.

"command": "npx", "args": ["-y", "elementor-mcp"]
View Config
Windows

Windows

Use cmd /c npx to launch via Command Prompt — required for correct process spawning on Windows.

"command": "cmd", "args": ["/c","npx","-y","elementor-mcp"]
View Config

Check platform-specific installation instructions to get started.
